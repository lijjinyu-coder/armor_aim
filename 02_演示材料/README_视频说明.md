## 主证据里各时刻的数值

| 时刻 | 屏幕上的数 | 说明 |
| --- | --- | --- |
| 1~5秒 | yaw_rel = -13.80°，dist 1.92m | 目标偏在一边，此时自瞄是关的，云台不动 |
| 9秒 | NO_ARMOR | 按了 F5 开自瞄，转向途中目标短暂出画 |
| 13秒 | yaw_rel = -0.71° | 云台自己转到位（-127.02° → -114.49°） |
| 22秒 | yaw_rel = +0.26°，pitch_rel = -0.89° | 稳在中心附近 |
| 34秒 | TIMEOUT，cmd 为空 | 目标丢失，发 distance=-1 |
| 48秒 | TIMEOUT，姿态不变 | 云台停住，不再用过期目标 |

这段是一次连续录制，没剪辑；录制期间云台只由算法命令驱动，没手工点过。
